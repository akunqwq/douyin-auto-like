# 抖音自动点赞

基于网页版抖音的 Tampermonkey 用户脚本，视频播放后计时10秒通过快捷键通道自动点赞，并自动跳过已点赞的视频，并支持睡眠定时自动暂停视频功能。

## 特性

- 自动点赞当前正在观看的未点赞视频，覆盖推荐流、搜索结果、精选、播放页。
- 延迟 10 秒再点赞：为用户提供一定时间进行判断，防止脚本自作主张。
- 通过`data-e2e-state` 确认点赞状态，已赞直接跳过。
- 通过 Z 键事件触发点赞，使用抖音视频平台自身的快捷键通道。
- 检测到手动取消点赞后不再干预该视频；滑走再滑回视为新的观看过程。
- 今日记录只保留一天，跨日刷新，避免占用性能存储。
- 可将今日累计刷的视频数据导出至JSON，以便统计。
- 睡眠定时自动暂停视频：内置 10 / 15 / 30 / 45 分钟、1 / 2 小时快捷预设，点选即启动；也可自定义小时与分钟。

## 温馨提示

抖音的「喜欢」会影响后续给你推什么内容，如替自己连续点了不少喜欢，之后刷到的内容也会发生变化。
具体会有什么影响不好说，介意的话，请谨慎使用本脚本。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展（Chrome、Edge、Firefox 等）。
2. 点击下方链接，Tampermonkey 弹出安装确认页后，点击「安装」。

   [点击安装脚本](https://raw.githubusercontent.com/akunqwq/douyin-auto-like/main/douyin-auto-like.user.js)

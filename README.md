# 抖音视频自动点赞Tampermonkey脚本
抖音官方原生快捷键通道实现，支持官方没有的睡眠定时功能。

## 特性

- 自动点赞当前正在观看的未点赞视频：推荐流、搜索页弹窗视频、首页精选。
- 为用户提供10秒作为操作缓冲。
- 抖音官方原生快捷键通道实现。
- 脚本操作前先确认人工操作状态，防止冲突干预。
- 今日刷视频ID数据可导出，方便用户分析（只保留一天）。
- 睡眠定时功能：快捷预设 + 自定义时间写入。

## ⚠️温馨提示 

抖音会根据「喜欢」优化推荐，脚本连续点赞可能改变你后续刷到的内容，影响程度因人而异，介意请谨慎使用！

## 安装教程

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展（Chrome、Edge、Firefox 等）。
2. 点击下方链接，Tampermonkey 弹出安装确认页后，点击「安装」。

   [点击安装脚本](https://raw.githubusercontent.com/akunqwq/douyin-auto-like/main/douyin-auto-like.user.js)
